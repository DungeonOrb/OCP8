Bienvenue dans le projet 8 OpenClassRoom: Kasa

Instruction pour lancer correctement le projet:
1. Dans Git Bash, naviguer dans OCP8/backend et faire -> npm start <-

2. Dans une autre fenêtre Git Bash, naviguer dans OCP8/frontend et faire -> npm run dev <-

3. Copier l'addresse donner par Git Bash dans la ligne "- Local: [adresse]" dans votre navigateur, normalement http://localhost:3001

4. Si vous souhaitez essayer la fonction d'ajout de propriété vous deverez vous connecter avec un compte hôte:
Email: host@test.com
Mot de passe: test1234

5. Si vous souhaitez essayer les tests unitaires, dans une autre fenêtre Git Bash naviguez dans OCP8/frontend et faire -> npm test -- --run <-
